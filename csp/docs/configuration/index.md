# 时钟、外设与 Pinmux

## 时钟配置

- 在“时钟配置”顶部展开“时钟源与工作模式”，选择时钟源模式。
- 在时钟树中设置复用器、PLL 倍频和总线分频。计算结果自动写入工程，不依赖时钟页面是否打开。
- 未启用、只读和数据库不支持的选项不可编辑。断开的输入、循环连接、非法分频和超范围频率会显示提示。
- 普通配置模式不能修改时钟树连线或删除节点。开发模式下仍可解锁布局编辑数据库。
- 保存工程会先等待频率及引脚联动完成，再保存同一份配置快照。

## 外设和 GPIO

- 在左侧选择外设，编辑工作模式及参数。条件参数随对应外设实例切换，多个串口实例互不串扰。
- 芯片视图中点击引脚，或在 Pinmux 表格中选择引脚，可打开该引脚的 GPIO 电气参数。
- 输入和输出方向切换时，不兼容的上拉、下拉、推挽或开漏设置会调整为该方向的默认值。
- 参数表遵守数据库中的只读、启用条件和可选值。数值超出范围时不会提交。

## Pinmux

1. 打开“芯片配置 → Pinmux”，按引脚名、脚位、信号或标签搜索。
2. 在“功能”下拉框选择复用信号。手动选择会锁定该引脚，避免外设模式切换时覆盖。
3. 修改或释放该引脚前，关闭“锁定”开关，再选择新功能或“未分配”。标签可以为空，非空时应为唯一的 C 标识符。
4. 对已定义信号映射的外设，模式启用后自动分配可用引脚；关闭模式时释放自动分配且未锁定的引脚。
5. 同一外设信号不能重复分配到两个锁定引脚。有冲突或缺少映射时显示提示，不执行部分自动分配。

## GPIO 代码生成

本次同步更新了仓库中的 `csp_hal_sp28038`：生成器使用所选物理引脚，在厂商 `pin_map.h` 中校验复用宏，生成 `GPIO_setPinConfig()`、方向、PAD 和输入滤波初始化。无效映射及重复信号会报错。

应用使用已安装的 HAL 软件包生成代码。要使用上述生成器修改，请通过软件包管理从仓库的 `csp_hal_sp28038` 文件夹重新安装；仓库根目录现有的 `.csppack` 压缩包尚未重新打包。

## 当前芯片数据范围

仓库目前只有 SP28038 芯片数据库。部分外设条目没有参数定义，标记为“待适配”；另有部分时钟及 USART/UART 定义沿用了 APM32F103 命名，与 SP28038 的 SCI 引脚表不一致。缺少对应映射的模式会被禁用，不能据此宣称这些外设已经完成芯片适配。

本次验证覆盖配置模型、界面交互、保存重建和 GPIO 模板渲染。时钟寄存器、其他外设初始化代码及目标板运行仍需逐项按 SP28038 手册和硬件验证。
